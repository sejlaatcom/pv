# منصة نقاطي — نظام النقاط التحفيزية للطلاب

منصة ويب متكاملة بلغة **PHP** وقاعدة بيانات **MySQL** لإدارة التحفيز في المدارس وحلقات
التحفيظ والدور النسائية والأكاديميات الرياضية والنوادي الصيفية: رصد النقاط، الأوسمة،
متجر الجوائز، الحضور، المهام، المسابقات مع التصحيح الآلي، والتقارير اللحظية.

بُنيت بـ PHP خالص (بدون Composer أو أي مكتبة خارجية) لتعمل على أي استضافة مشتركة.

## متطلبات التشغيل

- PHP 8.0 فأعلى مع الامتدادات: `pdo_mysql`, `mbstring`
- MySQL 5.7+ أو MariaDB 10.3+
- خادم ويب (Apache مع `mod_rewrite`، أو Nginx، أو خادم PHP المدمج للتطوير)

## التثبيت

### 1) الإعدادات

عدّل بيانات قاعدة البيانات في `app/config.php`، أو — وهو الأفضل — أنشئ ملفاً محلياً
لا يُرفع إلى المستودع باسم `app/config.local.php`:

```php
<?php
return [
    'db' => [
        'host' => 'localhost',
        'name' => 'noqati',
        'user' => 'db_user',
        'pass' => 'db_password',
    ],
    'app' => [
        'base_url' => '',            // اتركه فارغاً إذا كان الموقع في جذر النطاق
        'timezone' => 'Asia/Riyadh',
    ],
];
```

### 2) إنشاء الجداول

**من الطرفية (الأسهل):**

```bash
php database/install.php          # الجداول فقط
php database/install.php --demo   # الجداول + بيانات تجريبية كاملة
```

**أو من phpMyAdmin:** أنشئ قاعدة بيانات بترميز `utf8mb4_unicode_ci` ثم استورد الملف
`database/schema.sql`.

**لترقية تثبيت قائم** بعد تحديث المشروع (يضيف الأعمدة الجديدة دون المساس بالبيانات):

```bash
php database/migrate.php
```

### 3) التشغيل

**محلياً:**

```bash
php -S localhost:8000 -t public public/router.php
```

ثم افتح <http://localhost:8000>

**على استضافة مشتركة (cPanel):**

- الطريقة المفضّلة: اجعل مجلد الجذر (Document Root) للنطاق هو مجلد `public`.
- إذا لم تستطع تغيير مجلد الجذر: ارفع الملفات كما هي — ملف `.htaccess` في الجذر
  يوجّه الطلبات تلقائياً إلى `public`.

> ملاحظة أمنية: مجلد `public` وحده هو الذي يجب أن يكون متاحاً للمتصفح، وبقية المجلدات
> (`app`, `database`, `tests`) خارج نطاق الوصول المباشر.

### 4) إنشاء حساب الجهة

افتح `/register` وأنشئ حساب جهتك — ستُجهَّز لك تلقائياً بنود نقاط وأوسمة وجوائز جاهزة.

## بيانات الدخول التجريبية

بعد `php database/install.php --demo`:

| الدور | البريد | كلمة المرور |
|-------|--------|--------------|
| مدير الجهة | `admin@demo.local` | `123456` |
| مشرف | `supervisor@demo.local` | `123456` |

تشمل البيانات التجريبية: 28 طالباً في 4 مجموعات، حركات نقاط لـ 45 يوماً، حضور 20 يوماً،
مهاماً، 4 مسابقات، وجوائز وطلبات استبدال.

**بوابة الطالب/ولي الأمر:** لكل طالب رابط خاص بصيغة `/p/{رمز-المتابعة}` — تجده في صفحة
الطالب داخل لوحة التحكم مع زر نسخ وزر إرسال عبر الواتساب. ويستطيع الطالب الدخول من
`/student-login` بإدخال الرمز نفسه.

## بنية المشروع

```
public/                  ← مجلد الجذر للويب
  index.php              ← نقطة الدخول وجدول المسارات
  router.php             ← موجّه خادم PHP المدمج (للتطوير)
  assets/css/style.css   ← التنسيقات (RTL)
  assets/js/app.js       ← سكربتات الواجهة (بدون مكتبات)

app/
  config.php             ← الإعدادات (قاعدة البيانات، الهوية، المنطقة الزمنية)
  bootstrap.php          ← تحميل النواة
  lib/
    db.php               ← طبقة PDO (عبارات مُجهّزة فقط)
    helpers.php          ← دوال مساعدة (العرض، الروابط، الحماية، التنسيق)
    auth.php             ← المصادقة والصلاحيات
    models.php           ← الجهات، المجموعات، الطلاب، النقاط، الأوسمة، الجوائز
    modules.php          ← الحضور، المهام، المسابقات، الإحصاءات والتقارير
    charts.php           ← رسوم بيانية SVG مولّدة من PHP
    quiz_bank.php        ← بنك المسابقات الجاهزة
  controllers/           ← متحكمات الصفحات
  views/                 ← القوالب (site / auth / app / portal)

database/
  schema.sql             ← مخطط قاعدة البيانات
  install.php            ← المثبّت (مع خيار --demo)
  migrate.php            ← ترقية قاعدة بيانات قائمة
  seed.php               ← مولّد البيانات التجريبية

tests/run.php            ← اختبارات ذاتية لمنطق المنصة
```

**الموقع التعريفي:** `/` · `/features` · `/pricing` · `/faq` · `/contact`

`/students/{id}/export` — ملفات CSV بترميز UTF-8 مع BOM لتظهر العربية في Excel مباشرة.

## الحماية

- كلمات المرور مشفّرة بـ `password_hash()` (bcrypt).
- جميع الاستعلامات تستخدم **عبارات مُجهّزة** (Prepared Statements).
- رمز **CSRF** يُتحقق منه في كل طلب `POST`.
- تهريب كل المخرجات عبر `htmlspecialchars()`.
- **عزل البيانات بين الجهات**: كل استعلام مقيّد بالجهة، ومحاولة الوصول لسجل من جهة أخرى
  تُعيد 404.
- **صلاحيتان**: مدير الجهة (حذف وإدارة المستخدمين وبيانات الجهة) والمشرف (الرصد والمتابعة).
- تجديد معرّف الجلسة عند تسجيل الدخول والخروج.

## تخصيص الهوية

اسم المنصة وشعارها وبيانات التواصل وسعر الاشتراك كلها في قسم `brand` داخل
`app/config.php` — عدّلها مرة واحدة لتنعكس على كامل الموقع.

الألوان في أول ملف `public/assets/css/style.css` ضمن `:root` (اللون الأساسي `--brand`
واللون الذهبي `--gold`).
